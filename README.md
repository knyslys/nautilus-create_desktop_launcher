Simple nautilus script that allows .desktop file creation.

Dependencies:

Ubuntu:
sudo apt install yad

Fedora:
sudo dnf instal yad


Installation:

1. Install dependencies and download the file
2. Right click mouse button, click on properties
3. Click on Executable as Program
4. Copy file and paste: ~/.local/share/nautilus/scripts/
